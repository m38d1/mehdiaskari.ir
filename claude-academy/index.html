آبان ۱۴۰۵Anthropic۲۹ دوره۲۵ نشان

آکادمی Claude

هر ۲۹ دورهٔ Claude Academy (شرکت Anthropic) را تکمیل کرده‌ام و ۲۵ نشان تکمیل گرفته‌ام — از مبانی Claude و ساخت با API و پروتکل MCP تا استقرار سازمانی و چارچوب AI Fluency. فهرست کامل به‌تفکیک موضوع:

محصولات و مبانی Claude ۶

Claude 101

استفاده از Claude برای کارهای روزمره؛ از نخستین گفتگو و پرامپت‌نویسی مؤثر تا پروژه‌ها، artifactها، skillها و ابزارهای متصل.

Claude Code 101

ابزار کدنویسی عاملی که در ترمینال اجرا می‌شود؛ آشنایی با Claude Code، نحوهٔ کار و گردش‌کارهای اصلی برای انجام کار واقعی با آن.

Claude Code in action

اجرای جلسه‌های طولانی و خودکار Claude Code که بتوان به آن‌ها اعتماد کرد؛ هدایت، پیکربندی، خودکارسازی و راستی‌آزمایی.

Introduction to Claude Cowork

واگذاری کارهای چندمرحله‌ای به Claude در Cowork؛ راه‌اندازی فضای کار، دادن زمینه، اجرای چرخه‌های وظیفه و استفاده از افزونه‌ها برای پژوهش، اسناد و کارهای مرورگر.

Introduction to Claude Tag

Claude Tag (بتا) Claude را به فضای Slack تیم می‌آورد؛ اینکه چه کاری را به آن بسپارید، چگونه هدایت و اصلاحش کنید و عادت‌هایی که بازدهی شما و تیم را بیشتر می‌کند.

Claude Platform 101

ساختن روی پلتفرم Claude از پایه؛ مناسب توسعه‌دهندگانی که چند فراخوانی API داشته‌اند یا تنها از پنجرهٔ چت Claude استفاده کرده‌اند.

ساخت با Claude (API، MCP و عامل‌ها) ۷

Building with the Claude API

طیف کامل کار با مدل‌های Anthropic از طریق Claude API؛ پرامپت‌نویسی، استفاده از ابزار، RAG، عامل‌ها، MCP و الگوهای production.

Tool use with the Messages API

قابل‌اتکا، پاسخ‌گو و کم‌هزینه‌کردن استفاده از ابزار در Messages API و سپس افزودن ابزارهایی که Anthropic ارائه می‌دهد.

Introduction to Model Context Protocol

ساخت سرور و کلاینت MCP از صفر با SDK پایتون؛ سه اصل اصلی یعنی tools، resources و prompts که Claude را به سرویس‌های خارجی متصل می‌کند.

Model Context Protocol: Advanced topics

فراتر از مبانی MCP؛ sampling، notifications و roots همراه با مرور تعاملی هر جریان پروتکل.

Introduction to subagents

تجزیهٔ وظایف پیچیده میان subagentهای موازی Claude و ارکستره‌کردن قطعی آن‌ها.

Introduction to agent skills

ساخت، پیکربندی و اشتراک skillها در Claude Code؛ دستورالعمل‌های markdown قابل‌استفادهٔ مجدد که Claude خودکار به وظایف مرتبط اعمال می‌کند، از نخستین skill تا توزیع تیمی و عیب‌یابی.

Introduction to evals

ساخت یک eval کوچک روی دادهٔ خودتان برای انتخاب مدل Claude بر پایهٔ دقت و سپس هزینه؛ اصلاح پرامپت پیش از ارتقا و پایش مستمر پس از انتشار.

استقرار ابری و سازمانی ۵

Claude with Amazon Bedrock

یکپارچه‌سازی و استقرار Claude از طریق Amazon Bedrock؛ پیاده‌سازی API، استفاده از ابزار، خطوط RAG، عامل‌ها و اپلیکیشن‌های آمادهٔ production روی AWS.

Claude on Google Cloud

کار با مدل‌های Anthropic از طریق Agent Platform گوگل کلاد؛ راه‌اندازی، پرامپت‌نویسی، استفاده از ابزار، RAG، عامل‌ها و الگوهای استقرار production.

Deploying Claude Enterprise with confidence

پنج تصمیمی که نحوهٔ کار Claude در سازمان را شکل می‌دهد — ساختار و هویت، دسترسی، حاکمیت، هزینه و دیده‌پذیری — و ثبت آن‌ها در طرح rollout.

The AI-native SDLC playbook

دوازده play برای به‌کارگیری Claude در هر مرحله از چرخهٔ عمر توسعهٔ نرم‌افزار (SDLC)؛ ویژهٔ رهبران مهندسی، پلتفرم و امنیت که سازمانشان Claude Code دارد.

Building effective human-agent teams (beta)

مزایای گذار از AI تک‌نفره به چندنفره و اینکه چگونه تیم را برای این تغییر آماده کنید.

چارچوب و کاربردهای AI Fluency ۱۱

AI Fluency: Framework and foundations

همکاری مؤثر، کارآمد، اخلاقی و ایمن با AI با چارچوب 4D؛ Delegation، Description، Discernment و Diligence.

AI capabilities and limitations

ساخت مدل ذهنی دقیق از توانایی‌ها و محدودیت‌های مدل‌های زبانی بزرگ؛ پیش‌بینی توکن بعدی، دانش، حافظهٔ کاری، هدایت‌پذیری و محدودیت‌های context.

AI Fluency for builders

توانمندسازی سازندگان برای توسعهٔ AI fluency؛ افزایش اثرگذاری و کارایی ضمن حفظ مالکیت کامل مسیر از مسئله تا راه‌حل تحویل‌شده.

AI Fluency for creative work

توانمندسازی متخصصان خلاق برای تصمیم‌گیری آگاهانه و تحلیل‌محور دربارهٔ استفاده از AI در عمل خلاقانه، ضمن حفاظت از آنچه اثر را متعلق به آنان می‌کند.

AI Fluency for educators

به‌کارگیری چارچوب 4D توسط اعضای هیئت علمی، طراحان آموزشی و رهبران آموزشی در طراحی دوره، مواد یادگیری و عمل تدریس.

AI Fluency for pK–12 educators

ساخت AI fluency عملی برای مربیان pK-12 با چارچوب 4D؛ حمایت از یادگیری دانش‌آموز ضمن پایبندی به مأموریت و ارزش‌ها. با همکاری Teach For America.

AI Fluency for pK-12 Train the Trainer

توانمندسازی مربیان pK-12 برای رهبری آموزش AI fluency همکاران؛ با کیت کارگاه آمادهٔ اجرا مبتنی بر چارچوب 4D و پایبندی به مأموریت و ارزش‌های مربیان.

Teaching AI Fluency

تجهیز اعضای هیئت علمی و طراحان آموزشی برای تدریس و ارزیابی AI fluency در محیط‌های instructor-led؛ راهبردهای ارزیابی، طراحی تکلیف و کاربرد رشته‌ای بر پایهٔ چارچوب 4D.

AI Fluency for nonprofits

مهارت‌های همکاری عملی با AI برای سازمان‌های غیرانتفاعی با چارچوب 4D؛ پژوهش، نگارش، تحلیل داده و پذیرش سازمانی AI ضمن پایبندی به مأموریت و ارزش‌ها.

AI Fluency for small businesses

مهارت‌های همکاری عملی با AI برای صاحبان و کارکنان کسب‌وکارهای کوچک با چارچوب 4D؛ کاربرد در پژوهش، دادهٔ مشتری و عملیات روزمره ضمن پایبندی به مأموریت و ارزش‌ها.

AI Fluency for students

ساخت مهارت‌های AI fluency برای یادگیری، برنامه‌ریزی شغلی و موفقیت تحصیلی از طریق همکاری مسئولانه با AI؛ کاربرد چارچوب 4D در زندگی دانشجویی.
